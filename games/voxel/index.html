Connect with codes (no friends service needed)

Use this when friend codes don't work. The host sends an invite code to a friend (WhatsApp, Discord, email...), the friend sends back a reply code, and you are connected peer-to-peer. The host must be inside one of their worlds. Works best on normal home Wi-Fi; some school or office networks block direct connections.

Host: invite a friend into this world
Join: play in a friend's world
